# semantic reading editor

> Client-Facing Documentation
> Last Updated: 2026-05-10
> Version: 1.0

## Что делает эта функция

Эта функция превращает редактор из инструмента слоев и анимаций в семантический редактор чтения. Автор работает с тем, что реально видит читатель: панелями, ссылками на балуны, порядком чтения, звуками и движением по скроллу.

Детальная спецификация создания, редактирования, анимации, типографики, хвостов, FX и runtime export балунов вынесена в [`vdd-comics.editor-balloons-editor`](../vdd-comics.editor-balloons-editor/).

## Как это работает

Если совсем просто:

1. Автор размечает панели на странице.
2. Автор добавляет балуны через Balloon Editor v2 и связывает их с говорящими персонажами.
3. Автор задает порядок чтения.
4. Таймлайн управляет тем, когда появляются панели, балуны, звуки, фокус камеры и анимации слоев.
5. Режим локализации проверяет, помещаются ли русский, английский, хинди и другие языки.
6. Превью читателя показывает сцену на телефоне, планшете, десктопе и в режиме сниженного движения.

## Ключевые преимущества

- Автор редактирует поток чтения, а не только технические слои.
- Балуны становятся переиспользуемыми, локализуемыми и анимируемыми объектами через отдельный Balloon Editor v2.
- Звуки можно привязывать к конкретным моментам чтения.
- Редактор помогает проверить читаемость до публикации.
- Продукт может поддерживать guided-view чтение на телефоне, не теряя scroll-driven анимацию.

## Основная модель

```text
Панель       = куда смотрит читатель
Балун        = что читатель читает
Узел чтения  = когда это появляется
Таймлайн     = как это движется и звучит
Локализация  = как это переживает перевод
Превью       = понятно ли это читать на реальном устройстве
```

## Как начать

1. Откройте или создайте `.comics` документ.
2. Переключитесь в `Режим: Чтение`.
3. Разметьте панели и добавьте балуны через Balloon Editor v2.
4. Настройте порядок чтения.
5. Привяжите звуки и движения к узлам чтения.
6. Проверьте результат в `Лаборатория чтения`.
