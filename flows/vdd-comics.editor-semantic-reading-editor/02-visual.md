# Visual Mockups: semantic reading editor

> Version: 1.0
> Status: DRAFT
> Last Updated: 2026-05-10
> Requirements: [01-requirements.md](./01-requirements.md)

## Overview

ASCII mockups for a semantic reading editor where panels, balloon references, reading order, sound, and scroll animation are edited as one scene.

The examples are in Russian because the target authoring and review workflow must be readable for Russian-speaking users.

---

### Flow: Создание порядка чтения

```text
[Выбрать панель] -> [Добавить узел] -> [Выбрать балун]

```

## Component: Смысловая модель

```text
Панель       = куда смотрит читатель
Балун        = что читатель читает
Узел чтения  = когда это появляется
Таймлайн     = как это движется и звучит
Локализация  = как это переживает перевод
Превью       = понятно ли это читать на реальном устройстве
```
